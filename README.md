# নজরুল একাডেমি রিইউনিয়ন ২০২৬ — ফটো ফ্রেম ওয়েবসাইট

স্ট্যাটিক HTML/CSS/JavaScript; QR code নেই। নাম, ব্যাচ ও ছবি বদলানো যায় এবং PNG ডাউনলোড হয়।

## GitHub Pages-এ প্রকাশ
1. ZIP আনজিপ করুন। `index.html`, `script.js`, এবং `assets` ফোল্ডার রিপোজিটরির root-এ আপলোড করুন।
2. পুরোনো `index.html` থাকলে নতুনটি দিয়ে replace করুন (আগের ফাইলের backup রাখুন)।
3. Repository > Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save।
4. কয়েক মিনিট পর প্রদর্শিত GitHub Pages URL খুলুন।

GitHub Pages-এ আগে থেকে অন্য সাইট থাকলে পুরোনো ফাইলগুলো মুছে ফেলার আগে backup নিন। `assets/school.jpg` ও `assets/logo.jpg`-এর path অপরিবর্তিত রাখুন।

**নোট:** Google Fonts লোড না হলে ডিভাইসের বাংলা fallback font ব্যবহৃত হবে। PNG আউটপুট 1200×1200 px।
